# 액팅 소울 : 0 — 신들의 종언 (시즌 2 체험판)

시즌 2 설정을 바탕으로 만든 웹 액션 게임 체험판입니다. 0막 ~ 2막까지 플레이할 수 있습니다.

- 현재 버전: **v0.1.0**
- 실행 환경: 휴대폰·PC 브라우저 (Chrome, Safari 등)
- 외부 라이브러리 없음, 인터넷 연결 없이도 실행 가능

---

## 실행 방법

- **그냥 실행:** `index.html`을 브라우저로 엽니다.
- **GitHub Pages 배포:** 저장소 루트에 `index.html` 하나만 올리고 Pages를 켜면 됩니다. 이미지와 코드가 모두 이 파일 안에 들어 있습니다.
- 가로 화면과 이어폰 사용을 추천합니다.

## 조작법

| 동작 | 터치 | 키보드 |
|---|---|---|
| 이동 | 왼쪽 화면 드래그 | WASD / 방향키 |
| 공격 (누르고 있으면 3연격) | 공격 | J |
| 회피 (닿기 직전이면 완벽 회피) | 회피 | K / Space |
| 스킬 | 공허 / 흡융 | L |
| 교대 (이든 ↔ 네시스) | 교대 | Q |
| 링크 0 : 공허 & 흡융 (게이지 100%) | 링크 | E |
| 일시정지 | ❚❚ | Esc / P |

## 게임 구성

| 막 | 내용 | 전투 |

| 0막 프롤로그 — 침묵의 약속 | 흡융의 탑, 스테일 마을 대장간, 방주 레지스트리 도착 | 없음 |

## 파일 구성

```
index.html      완성본 (아래 파일들을 합친 결과물, 배포용)
build.py        원본 + 이미지를 합쳐서 dist/index.html 생성
src/
  shell.html    화면 구조와 CSS
  core.js       화면 크기, 저장, 효과음, 입력
  story.js      등장인물, 대본, 대화 진행, 배경 그림
  battle.js     캐릭터, 적, 전투 구성, 적 AI, 튜토리얼, 전투 화면
  main.js       메인 루프
assets/         (빌드할 때 필요)
  logo.webp     타이틀 로고
  eden.jpg      이든 초상화
  nesis.jpg     네시스 초상화
```

## 다시 빌드하기

`src/`와 `assets/`가 `build.py`와 같은 폴더에 있어야 합니다.

```
python3 build.py
```

`dist/index.html`이 새로 만들어집니다. `shell.html`의 `%%LOGO%%`, `%%EDEN%%`, `%%NESIS%%` 자리에 이미지가, `%%JS%%` 자리에 스크립트 4개가 순서대로(core → story → battle → main) 들어갑니다.

## 자주 고치는 곳

### 대사·스토리 — `story.js`의 `RAW`

| 줄 형식 | 의미 |
|---|---|
| `#card 제 1막\|제목` | 막 제목 카드 |
| `@bg forge` | 배경 전환 |
| `이든: 대사` | 인물 대사 (이름은 `SPK`에 등록된 인물) |
| `> 문장` | 나레이션 |
| `[sys] 문장` | 시스템 메시지 |
| `!battle tut` | 전투 시작 (`tut`, `outpost`, `abimor`, `phasis`) |
| `!end` | 체험판 종료 화면 |

배경 이름: `tower`, `forge`, `ark`, `chamber`, `plaza`, `unity`, `alert`, `outpost`, `cliff`, `moles`, `waste`, `phasis`

새 인물을 추가하려면 `SPK`에 `'이름':{c:'#색상',e:'글자',full:'표시 이름'}`을 넣습니다.

### 캐릭터 성능 — `battle.js`의 `CH`

- `maxhp`: 최대 체력 (이든 520, 네시스 600)
- `spd`: 이동 속도
- `combo`: 3연격 각 타의 `dmg`(피해), `r`(사거리), `d`(동작 시간)
- `skill.cd`: 스킬 쿨타임 (공허 9초, 흡융 10초)

### 적 난이도 — `battle.js`의 `ET`와 `AI`

- `ET`의 `hp`, `dmg`, `spd`: 적 기본 능력치
- 보스 체력: 아비 1400, 모르 1850, 파시스 3600
- `AI.abi`, `AI.mor`, `AI.phasis` 안의 `dmg:` 값과 `t:`(경고 표시 시간): 보스 패턴 피해와 반응 시간

### 전투 구성 — `battle.js`의 `BATTLES`

- `allies`: 함께 싸우는 아군 (`ALLY_DEF`에 등록된 인물)
- `waves`: 방어전 웨이브 구성, 예) `[['claw',6],['spitter',4]]`
- `bosses`: 등장 보스

## 저장

브라우저 localStorage의 `as0s2_save` 키에 막 해금 상태와 효과음 설정만 저장합니다. 브라우저 데이터를 지우면 초기화됩니다.

## 설정 관련 메모

- 황금 공명은 28막에서 처음 개화하므로 체험판에서는 쓰지 않고, 링크 시스템의 "0. 공허 & 흡융"을 합동기로 사용했습니다.
- 권능 문서가 비어 있어서 스킬 효과([태초의 공허], [흡융])는 설정에 맞춰 임시로 정했습니다.
- 하급 피조물(아비, 모르, 파시스)은 구상 문서대로 1페이즈입니다. 파시스는 체력 50% 이하에서 격노해 패턴이 빨라집니다.
