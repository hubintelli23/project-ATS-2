# 액팅 소울 : 0 — 신들의 종언 (시즌 2 체험판)

시즌 2 설정을 바탕으로 만든 **3D 액션 JRPG** 웹 체험판입니다. 0막 ~ 2막까지 플레이할 수 있습니다.

- 현재 버전: **v0.4.0**
- 장르: 액션 JRPG · 시점: 3인칭 백뷰 (명조: 워더링 웨이브 방식)
- 실행 환경: **PC와 휴대폰 모두** (WebGL2 지원 Chrome, Safari, Edge). 마지막으로 쓴 입력에 따라 PC/모바일 화면이 자동으로 바뀌고, 설정에서 고정할 수도 있습니다.
- 업데이트 기록: [`updates.json`](updates.json)
- 외부 라이브러리 없음 — 자체 미니 3D 엔진(`js/engine.js`) 사용, 인터넷 연결 없이도 실행 가능

---

## 실행 방법

- **그냥 실행:** 폴더째로 두고 `index.html`을 브라우저로 엽니다. (파일들이 서로를 불러오므로 폴더 구조를 유지해야 합니다)
- **GitHub Pages 배포:** 이 폴더 안의 모든 파일·폴더를 저장소 루트에 그대로 올리고 Pages를 켭니다.
- 가로 화면과 이어폰 사용을 추천합니다.

## 조작법 (통일 조작 체계)

| 동작 | PC | 휴대폰 |
|---|---|---|
| 이동 | WASD | 왼쪽 화면 드래그 |
| 시점 회전 | 마우스 (화면을 한 번 클릭하면 시점 고정) · 방향키 | 오른쪽 화면 드래그 |
| 회피 (닿기 직전이면 완벽 회피) | Shift | 회피 |
| 대쉬 | 마우스 우클릭 | 대쉬 |
| 공격 | 마우스 좌클릭 | 공격 |
| 강공격 | 마우스 좌클릭 0.5초 홀딩 | 공격 길게 누르기 |
| 점프 | Space | 점프 |
| 점프 공격 | Space → 좌클릭 | 점프 → 공격 |
| 점프 강공격 | Space → Ctrl + 좌클릭 | 점프 → 공격 길게 누르기 |
| 스킬 1 · 스킬 2 | Q · E | Q · E 버튼 |
| 궁극기 — 링크 0 : 공허 & 흡융 | R (게이지 100%) | 링크 |
| 캐릭터 전환 (이든 ↔ 네시스) | Tab | 교대 |
| 아이템 줍기 (상호작용) | F | 줍기 버튼 / 안내 문구 터치 |
| 지도 | M | 지도 |
| 설정 (일시정지) | Esc | ❚❚ |

홀딩 기준은 모두 0.5초입니다. 대화 중에는 클릭 · Space · Enter · F로 다음 대사로 넘어갑니다.

### 마스터 모드 (테스트·감상용)

타이틀의 **마스터 모드** 버튼, 또는 전투 중 **Esc → 마스터 모드**에서 엽니다. 켜기/끄기와 항목별 선택이 저장됩니다.

| 항목 | 내용 |
|---|---|
| 스토리·전투 건너뛰기 버튼 | 대화 중 `막 건너뛰기 ⏭` (남은 막 전체), 전투 중 `전투 건너뛰기 ⏭` (즉시 승리) |
| 쿨타임 제거 | Q·E 스킬, 교대, 회피, 대쉬 대기 시간 없음 |
| 무적 | 이든·네시스, 우니타스 아군, 방어막 발생기 |
| 링크 게이지 무한 | R 궁극기를 계속 사용 |
| 공격력 10배 | 플레이어 공격 피해 10배 |
| 모든 막 열기 | 막 선택 잠금 해제 |

**전투 바로가기:** 튜토리얼 · 전초기지 방어전 · 아비 & 모르 · 파시스 중 하나를 바로 시작하고, 끝나면 그 뒤 이야기로 이어집니다.
코드 위치: 설정 값은 `js/core.js`의 `SAVE.master`, 창과 건너뛰기는 `js/story.js`, 전투 적용은 `js/battle.js`(`M('항목')`로 확인).

### 캐릭터별 기술

| | 이든 (대행자) | 네시스 (집행자) |
|---|---|---|
| 무기 | 센티아(푸른 전기) + 센수스(보랏빛 폭풍) 쌍검 | 이럽디오(푸른 불꽃 대검), 클라우스룸은 등에 멤 |
| 기본 공격 | 3연격, 마지막 타 연쇄 번개 | 3연격, 마지막 타 불꽃 파동 |
| 강공격 | 센수스 회전베기 (2회 타격) | 대검 내려찍기 |
| Q | 태초의 공허 — 적을 끌어당겨 삼키는 장판 | 흡융 — 주변 적 흡수, 회복, 적 탄환을 아군 구슬로 전환 |
| E | 센티아 뇌격 — 최대 5체 연쇄 번개 + 경직 | 이럽디오 폭염 — 부채꼴 불꽃 파동 3개 |

## 파일 구성

```
index.html            시작 파일 (화면 틀 + 스크립트 불러오기)
README.md             설명서 (이 파일)
updates.json          업데이트 기록 (버전별, JSON)
css/style.css         화면 디자인
js/
  engine.js           미니 3D 엔진 (WebGL2) — 도형, 노드, 렌더러
  core.js             화면 크기, 저장, 효과음, 입력(조작 체계)
  story.js            등장인물, 대본, 대화 진행, 대화 장면 3D 무대
  battle.js           전투 규칙, 캐릭터 능력치, 적 AI, 튜토리얼, 전투 화면
  main.js             시작과 메인 루프
assets/               ← 나중에 추가·교체할 요소 (분리된 파일)
  avatars.js          아바타 캐릭터 (이든, 네시스, 우니타스, 적, 보스, 카로·오사)
  weapons.js          무기 · 아티팩트 (센티아, 센수스, 이럽디오, 클라우스룸, 적 무기)
  effects.js          이펙트 (베기 궤적, 충격파, 번개, 입자, 공격 예고 표시, 투사체, 피해 숫자)
  items.js            아이템 (에테르 결정, 링크 파편, 사념 정수)
  backgrounds.js      배경 (대화 장면 12종 + 전투 맵 4종, 방어막 발생기)
  img/                로고, 대화창 초상화 (logo.webp, eden.jpg, nesis.jpg)
```

불러오는 순서: `engine → weapons → avatars → effects → items → backgrounds → core → story → battle → main`

## 요소 추가하기

각 파일 맨 위 주석에 추가 방법이 적혀 있습니다. 요약:

### 아바타 캐릭터 — `assets/avatars.js`

```js
AVATARS.새아이디 = {
  name:'표시 이름', kind:'dual',      // dual / great / spear / chop / cast / beast
  shadow:.45,
  build(){ const R = humanoid({key:'새아이디', skin:'#..', hair:'#..', coat:'#..', ...});
           equip(R,'무기아이디','R'); return R; },
};
```
`humanoid()` 옵션: `skin, hair, hairTip, hairLong, bun, streak, coat, coat2, pants, tail, skirt, neon, eye, sleeve, glove, boots, bulk(체격), scale(키), plates(갑옷), core(가슴 발광), helmet`

### 무기 · 아티팩트 — `assets/weapons.js`

```js
WEAPONS.새아이디 = { name:'이름', owner:'주인', desc:'설명', trail:'#색', rest:[x,y,z],
  build(){ /* 손잡이 원점, 칼날은 -Y 방향 */ return Node(...); } };
```

### 이펙트 — `assets/effects.js`

```js
FX.spawn({ life:.5, draw(e,k){ R3.draw(FX.m.sph, mat(x,y,z,0,크기), {mode:2, tint:'#색', a:k}); } });
```

### 배경 — `assets/backgrounds.js`

```js
BACKGROUNDS.새아이디 = { name:'이름', cfg:cfgOf({sky:['#위','#아래'], fog:'#안개', fogN:15, fogF:80}),
  cast:[{id:'eden',dx:-.9,dz:0,face:Math.PI/2}],
  build(o){ return { draw(t){ ... } }; } };
```
대본에서 `@bg 새아이디`로 부릅니다. 전투 맵으로 쓰려면 `js/battle.js`의 `BATTLES`에서 `arena:'새아이디'`.

### 아이템 — `assets/items.js`

```js
ITEMS.새아이디 = { name:'이름', desc:'설명', col:'#색', drop:.1,
  use(){ /* 효과 */ return '화면 문구'; } };
```

### 3D 모델 파일(GLB 등)로 바꾸고 싶을 때

지금은 모든 모양을 코드로 만듭니다(도형 조합). 나중에 모델 파일을 쓰려면 모델 불러오기 기능을 엔진에 추가한 뒤, 각 정의의 `build()`(와 캐릭터의 `anim()`)만 교체하면 됩니다. 게임 규칙 파일은 건드리지 않아도 됩니다.

## 자주 고치는 곳

### 대사·스토리 — `js/story.js`의 `RAW`

| 줄 형식 | 의미 |
|---|---|
| `#card 제 1막\|제목` | 막 제목 카드 |
| `@bg forge` | 배경 전환 |
| `이든: 대사` | 인물 대사 (`SPK`에 등록된 인물) |
| `> 문장` | 나레이션 |
| `[sys] 문장` | 시스템 메시지 |
| `!battle tut` | 전투 시작 (`tut`, `outpost`, `abimor`, `phasis`) |
| `!end` | 체험판 종료 화면 |

배경 아이디: `title`, `tower`, `forge`, `ark`, `chamber`, `plaza`, `unity`, `alert`, `outpost`, `cliff`, `moles`, `waste`, `phasis`

### 수치 — `js/battle.js`

- `CH`: 이든·네시스 체력(`maxhp`), 속도(`spd`), 3연격(`combo`), 스킬 쿨타임(`q.cd`, `e.cd`)
- `ET`: 적 체력·피해·속도. 보스 체력: 아비 1400, 모르 1850, 파시스 3600
- `AI`: 보스 패턴의 `dmg:`(피해), `t:`(예고 시간)
- `BATTLES`: 아군, 웨이브 구성, 보스
- `S = 1/30`: 판정 좌표(px) → 3D 미터 변환 비율

## 설정 관련 메모

- 황금 공명은 28막에서 처음 개화하므로 체험판에서는 쓰지 않고, 링크 시스템의 "0. 공허 & 흡융"을 궁극기(R)로 사용했습니다.
- 권능 문서가 비어 있어서 스킬 효과(Q·E·강공격)는 설정에 맞춰 임시로 정했습니다.
- 하급 피조물(아비, 모르, 파시스)은 구상 문서대로 1페이즈입니다. 파시스는 체력 50% 이하에서 격노합니다.
